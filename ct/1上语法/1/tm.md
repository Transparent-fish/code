## 题目描述

小 C 给了你一个方程：
$$
\begin{cases}
x + y = \frac{(x^2 + 2xy + y^2)^2} {(x + y)^4} + 10^{9} - 1\\
\end{cases}
$$

他告诉了你 $x$ 的值，他想问你 $y$ 是多少？

## 输入格式

一行一个整数 $x$。

## 输出格式

一行一个整数表示 $y$ 的值，数据保证存在解。

```input1
0
```

```output1
100000000
```

## 说明 / 提示

$1 \leq x \leq 10^{18}$。

对于 $(a + b)^2$ 有 $(a + b)^2 = a^2 + 2ab + b^2$。
